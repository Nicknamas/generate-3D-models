## Тематика сайта, название

3D генерация моделей по запросам пользователей

__Название проекта: 3AI.

__Суть__: Веб-приложение для генерации 3д моделей по запросу и возможность взаимодействия с ними (посмотреть и ещё что-то).

## Цель и задачи системы

__Цель__: Предоставить обычным пользователям возможность доступно и просто генерировать 3D модели 

__Задачи системы:__

- Реализовать клиент приложения на Vue.js + Jinja2
- Развернуть бекенд с базами данных (Possgres, Redis)
- Построить pipeline взаимодействия бекенда и ИИ
- Связать бекенд и реализованный интерфейс в полноценное и функциональное приложение
- Задеплоить на сервере

## Целевая аудитория

- Инди-разработчики
- Дизайнеры, которые не умеют в 3D, ничего не нашли, но знают, что хотят
- Профессионалы, которые хотят упростить рутину 

## Содержание сайта

- Интерфейс для взаимодействия с ИИ путём введения промптов
- Личный профиль, где можно посмотреть информацию о себе
- История чатов с ИИ
- Примеры 3D моделей


## Функциональные возможности

- Написать промпт ИИ для генерации 3D модели
- Скачать сгенерированную модель
- Посмотреть на клиенте сгенерированную модель (под вопросом)
- Просмотр сессий с ИИ
- Возможность пополнить баланс
- Возможность посмотреть галлерею сгенерированных моделей
